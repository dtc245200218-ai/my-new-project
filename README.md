# My New Project

## Giới thiệu

Đây là dự án thực hành Git và GitHub, giúp làm quen với việc quản lý mã nguồn và đồng bộ dữ liệu giữa máy tính cá nhân với GitHub.

## Mục tiêu

- Khởi tạo Local Repository bằng Git.
- Kết nối Local Repository với Remote Repository.
- Thực hành các lệnh git add, git commit và git push.
